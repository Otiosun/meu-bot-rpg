# Legacy BC commands

Esta pasta guarda comandos da antiga base Black Clover que foram removidos do carregamento automatico.

O loader atual de `index.js` carrega apenas arquivos `.js` diretamente dentro de `comandos/`, entao estes arquivos ficam preservados, mas inativos.

Para reativar algum comando legado, mova o arquivo de volta para `comandos/` e revise as dependencias antes de ligar em producao.
