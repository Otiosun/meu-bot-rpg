PACOTE DE INFORMAÇÕES DAS ÁRVORES - CLOVER MULTICOLOR
Mana, Físico e Magia para preparação do site
================================================================================

FINALIDADE
--------------------------------------------------------------------------------
Este arquivo pode ser enviado diretamente para quem vai preparar as páginas do site.
Ele contém descrição, desenho rápido, nomes, IDs, preços, requisitos, efeitos,
aprovações, aliases e dados técnicos das definições oficiais carregadas pelo bot.

Fonte: data/clover/trees/*.json | Total documentado: 207 nós.

PÁGINAS SUGERIDAS
--------------------------------------------------------------------------------
1. Mana: usa a árvore real `mana`.
2. Físico: usa a árvore real `fisico`.
3. Magia: página conjunta, com três abas ou blocos:
   - Criação: árvore real `criacao`.
   - Reforço: árvore real `reforco`.
   - Suporte: árvore real `suporte`.

IMPORTANTE PARA O DESENVOLVEDOR
--------------------------------------------------------------------------------
- "Magia" é uma página agregadora. Não existe um treeId `magia` para compra.
- O site não deve recalcular requisitos, descontos ou disponibilidade sozinho.
- O JSON deste arquivo é uma referência humana; a API é a fonte operacional.
- Preço listado aqui é o preço base. O preço efetivo pode receber desconto.
- Nós com aprovação não devem exibir compra comum.
- Em Suporte, use sempre o status da API: básicos podem aparecer disponíveis e
  nós sensíveis/avançados aparecem como aprovação. Há textos históricos no projeto
  dizendo "bloqueado"; o estado calculado da API resolve qual ação pode ser mostrada.

O QUE A API JÁ ENTREGA
--------------------------------------------------------------------------------
GET /trees
  Entrega as cinco definições: mana, fisico, suporte, criacao e reforco.
  Cada definição contém: id, name, subtitle, aliases, routes, nodes, edges e goals.

GET /trees/:treeId
  Entrega a definição e o estado do player: ownedIds, progresso por rota, PH,
  desconto, nodeStates, requisitos faltantes, custo base, custo efetivo e status.

POST /trees/:treeId/purchase
  Body: { "nodeId": "id_do_no" } ou { "nodeAlias": "Nome do Nó" }.
  A API aplica as mesmas travas do bot e bloqueia falta de PH, requisito ou aprovação.

STATUS QUE A INTERFACE DEVE RESPEITAR
--------------------------------------------------------------------------------
owned: já comprado.
available: pode comprar.
no_ph: requisitos atendidos, mas falta PH.
locked: faltam requisitos.
approval: exige aprovação narrativa/ADM.

CAMPOS IMPORTANTES DE CADA NÓ
--------------------------------------------------------------------------------
id, name, route, tier, cost, shortEffect, effect, requires, requiresAny, unlocks,
requiresApproval, aliases, tags e metadata. O site pode decorar livremente, mas
deve manter esses identificadores para continuar sincronizado com o bot.

================================================================================
ID real na API: reforco
Nome oficial: Árvore de Reforço
Subtítulo: Buff mágico no corpo e nos atributos físicos
Descrição: Reforço é buff mágico no corpo e atributos físicos. Ele não aumenta automaticamente dano de projéteis, esferas ou formas criadas.
Quantidade de rotas: 7
Quantidade de nós: 25

ROTAS
--------------------------------------------------------------------------------
- Reforço [base]
  A base do Reforço permite fortalecer corpo físico com magia antes das especializações.
- Intensidade [intensidade]
  A rota de Intensidade define o valor do buff físico: +10%, +20% ou +30%.
- Estabilidade [estabilidade]
  A rota de Estabilidade define duração, segurança e menor desgaste. Quanto maior, menos o reforço oscila ou cobra do corpo.
- Foco de Atributo [foco]
  A rota de Foco de Atributo define quantos atributos podem ser buffados no mesmo feitiço.
- Invencível [invencivel]
  A rota Invencível é a rota de autobuff. O personagem reforça a si mesmo.
- Invicto [invicto]
  A rota Invicto é a rota de buff em outros. Deve conversar com Benção/Suporte no futuro.
- Junção de Forma [juncao]
  A rota de Junção de Forma liga Reforço com manifestação, área, armadura, aura, arma ou campo.
